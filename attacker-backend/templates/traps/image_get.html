罠②: <img src> による GET CSRF

送金 API が GET でも処理してしまう実装だった場合、こんな単純なコードで攻撃が成立する。

<img src="{{ victim_api_base }}/api/transfer/?to=mallory&amount=1">

※ 本サンプルの送金 API は POST 限定なので、これは 失敗例 として観察できる。 DevTools の Network タブで 405 Method Not Allowed が返ることを確認すること。
「GET で副作用を起こすな」という原則の重要性が体感できる罠。
